# New Type of Companion Bot

一款正在开发中的情感陪伴聊天机器人。

## 项目简介

本项目旨在构建一个能够提供真实情感陪伴体验的 AI 聊天机器人，不仅具备上下文记忆与情感识别能力，还通过表情包系统、webUI 界面和 Soul 核心机制，打造更贴近人类交流习惯的互动方式。

## 当前状态

🚧 **开发中** — 核心模块持续迭代，功能尚未完全稳定。

## 技术栈

- Python
- 自研 Soul 核心（记忆、情感、意图系统）
- WebUI 交互界面
- 表情包系统（meme engine）

## 目录结构

| 目录 | 说明 |
|------|------|
| `app/` | 主应用代码 |
| `webui/` | Web 界面 |
| `data/` | 数据存储 |
| `dm/` | 对话管理相关 |
| `memes/` | 表情包资源 |

## 启动方式

```bash
start.bat
```

或

```bash
pip install -r requirements.txt
# 然后运行主程序
```
